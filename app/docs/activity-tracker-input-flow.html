🤔 결정해주실 것

  • Q1. Todo는 "완료 시 카운트"가 맞나요? 아니면 "추가 시점부터 카운트"?
    • 완료 시 → "실제 한 일"만 잡혀서 정확
    • 추가 시 → "계획"까지 잡혀서 더 빨리 카운트 증가
  • Q2. Routine은 ⓐ 사전 태그 vs ⓑ 매일 메모 — 어느 쪽?
  • Q3. 한 항목에 #태그 여러 개 허용? (예: #논문읽기 #글쓰기)
  • Q4. 태그 표시 색은 어떻게 정할까요?
    • 자동 (태그명 해시 → 색)
    • 수동 (설정에서 태그별 색 지정 가능)
    • 혼합 (자동 기본값 + 수동 덮어쓰기)
  • Q5. 추적기 위치 — 홈 상단(눈에 띄게) vs 중간(스케줄 다음) vs 하단(부담 덜)?
