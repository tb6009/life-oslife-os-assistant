v0.7 — Stage 7
루틴 + 리포트/회고 + MI 공감 대화
2026-05-03 ~ 05-05
7315b16 → 3c180f9
습관 추적, 자동 리포트, 회고 시스템, 하루 대화 스타일 전면 개편. "기록하고 돌아보고 개선하는" 완전한 생산성 사이클 완성.
디자인 결정: AI가 바로 리스트를 주면 딱딱한 느낌. 동기면담(MI) 4원칙 적용: 경청/반영 → 열린 질문 → 공감 먼저 → 자율성 존중. "정리해드릴까요?" 물어보고 동의 후 제공.
구분내용
추가루틴 시스템: 체크 토글 + 연속 일수 + 🔥(3일+) + "잊지 않으셨죠?"
추가주간 리포트: "이번 주는 7일 중 5일을 기록하셨어요..." (자동 생성)
추가월간 리포트: 건강/감정/루틴/활동 4섹션 종합 (자동 생성)
추가주간 회고: 다음 주 다짐 + 한줄 소감 (직접 입력)
추가월간 회고: 기억에 남는 순간 + 다음 달 목표 + 나에게 한 마디
변경하루 대화: MI 공감 스타일 — 바로 리스트 금지, 공감 → 질문 → 정리 제안
추가감정 컬러 10색: 기쁨 평온 설렘 감사 무기력 불안 짜증 슬픔 피곤 외로움
변경폰트: Outfit + Noto Sans KR → Inter(제목) + DM Sans(본문)
추가Recommendation 컨텍스트: 상단 맥락 요약 + 체크 가능 항목
기술DB 12개 테이블 (weekly_reviews, monthly_reviews, routines, routine_logs 추가)
