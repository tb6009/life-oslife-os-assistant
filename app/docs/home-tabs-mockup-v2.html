🎨 v0.1에서 가져온 5가지 공통 디자인 언어

  • 1. 섹션 헤더 형식 — UPPERCASE TRACKING + 우측 메타 일관 적용 (Today/Routine/Recommendation/Todo/Activity/Completed 모두)
  • 2. 주차/구간 네비 — [← 라벨 →] 패턴 (현재 Completed에 있던 것을 Activity의 '최근 7일'에도 확장 가능)
  • 3. 통계 카드 3열 — 회색 배경 + 컬러 숫자 + 작은 라벨 (Completed는 녹색, Activity는 후속에서 적용 가능)
  • 4. 날짜/카테고리 그룹 — border-bottom: 1px solid 작은 헤더 + 그 아래 항목 (Completed의 날짜 그룹 → Activity의 태그 그룹에 같은 패턴)
  • 5. 라인 항목 — 좌측 컬러 보더 2px + 절제된 회색 본문 + 작은 메타 (Todo/Activity 항목/Completed 항목 모두 동일 패턴)

결과: Activity 탭은 기존 그라데이션 박스를 벗고 v0.1 톤으로 정돈됨. Daily 탭은 Todo 항목이 v0.1 라인 스타일 적용. Completed 탭은 그대로(이미 v0.1 디자인).
