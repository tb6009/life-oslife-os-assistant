# Life OS Design Guide v1 (초안)

> 2026-05-05 | UI/UX 통합 디자인 가이드라인

## 1. 디자인 철학

### 핵심 원칙
- **텍스트 중심**: 형태를 최소화하고, 텍스트와 여백으로 구조를 만든다
- **단일 액센트**: 하나의 색(블루)만 의미 있게 사용한다
- **데이터 기반**: 모든 제안과 리포트는 축적된 데이터에서 나온다
- **대화형**: 정보를 일방적으로 전달하지 않고, 사용자와 대화한다

### 브랜드 키워드
`미니멀` `따뜻한` `실용적` `개인적` `차분한`

## 2. 컬러 시스템

### 기본 팔레트

| 용도 | 이름 | Hex | 사용처 |
|------|------|-----|--------|
| 강조/제목 | Black | `#000000` | 제목, 선택된 날짜, 볼드 텍스트 |
| 본문 | Dark Gray | `#333333` | 본문 텍스트, 체크 항목 |
| 보조 | Mid Gray | `#808080` | 보조 설명, 라벨 설명 |
| 비활성 | Light Gray | `#B3B3B3` | 비활성 탭, 완료 항목, 플레이스홀더 |
| 구분선 | Border | `#E6E6E6` | 섹션 구분, 입력 테두리, 미달성 차트 |
| 서브 배경 | Subtle | `#F8F8F8` | 입력 필드 배경 |
| 카드 배경 | Card | `#FAFAFA` | 요약 카드, 리포트 배경 |
| 배경 | White | `#FFFFFF` | 전체 배경 |

### 기능 컬러

| 용도 | 이름 | Hex | 사용처 |
|------|------|-----|--------|
| 액센트/달성 | Blue | `#60A5FA` | 달성 차트, 활성 탭, 버튼, 링크 |
| 액센트 진함 | Blue Dark | `#3B82F6` | 차트 하이라이트 (마우스오버) |
| 건강 상태 | Green | `#059669` | 건강 기록 태그 배경 |
| 감정 상태 | Violet | `#8B5CF6` | 감정 기록 태그 배경 |

### 감정 컬러 매핑

| 감정 | Hex | 비고 |
|------|-----|------|
| 기쁨 | `#FBBF24` | 골드 — 밝고 따뜻한 |
| 평온 | `#60A5FA` | 블루 — 차분한 |
| 설렘 | `#F472B6` | 핑크 — 생기 있는 |
| 감사 | `#34D399` | 민트 — 부드러운 |
| 무기력 | `#94A3B8` | 슬레이트 — 무채색 |
| 불안 | `#A78BFA` | 바이올렛 — 불안정 |
| 짜증 | `#FB923C` | 오렌지 — 뜨거운 |
| 슬픔 | `#818CF8` | 인디고 — 깊은 |
| 피곤 | `#CBD5E1` | 라이트그레이 — 에너지 낮음 |
| 외로움 | `#C4B5FD` | 라벤더 — 조용한 |

### 컬러 사용 규칙

```
1. 배경은 항상 #FFFFFF
2. 차트에서 "달성" = #60A5FA, "미달성" = #E6E6E6 (2색만)
3. 감정만 예외적으로 다색 사용 (감정 컬러 매핑)
4. 빨강/초록/노랑 신호등 컬러 사용 금지
5. 액센트 컬러의 배경 사용 시 10~15% opacity
```

## 3. 타이포그래피

### 폰트 패밀리

| 용도 | 폰트 | 로드 |
|------|------|------|
| 영문 제목/라벨 | Outfit | Google Fonts, Variable |
| 한글 본문 | Noto Sans KR | Google Fonts, 300/400/500/700 |

### 타입 스케일

| 역할 | 폰트 | 크기 | 무게 | 컬러 | 사용처 |
|------|------|------|------|------|--------|
| 날씨 온도 | Outfit | 5.4rem | 300 | Black | 날씨 헤더 |
| 페이지 제목 | Outfit | 1.3rem | 700 | Black | Diary, 하루, Settings |
| 인사말 | Outfit | 1.5rem | 700 | Black | Good Morning |
| Today 요일 | — | 1.1~1.26rem | 600 | Black | "월요일 — 2건" |
| 섹션 라벨 | Outfit | 0.6rem | 500 | #B3B3B3 | SCHEDULE, ROUTINE 등 |
| 본문 | Noto Sans KR | 0.82~0.84rem | 400 | #333333 | 일정, 대화, 설명 |
| 보조 텍스트 | Noto Sans KR | 0.72~0.78rem | 400 | #808080 | 부가 정보, 시간 |
| 캡션 | — | 0.6~0.65rem | 400~500 | #B3B3B3 | 태그, 범례, 날짜 |

### 라벨 규칙

```
- 섹션 라벨: Outfit, 0.6rem, 500, #B3B3B3, UPPERCASE, letter-spacing 0.1em
- 예: "SCHEDULE", "ROUTINE", "EMOTION", "DAILY REVIEW"
- 라벨과 콘텐츠 사이 간격: 6~8px
- 라벨 위 간격: 18~20px
```

### 입력 필드

```
- 모든 input/textarea: font-size 16px (iOS 확대 방지)
- 배경: #F8F8F8
- 테두리: 1px solid #E6E6E6
- 모서리: 6px (작은 입력), 8~10px (textarea)
- 패딩: 8~10px
```

## 4. 간격 시스템

### 기본 단위: 4px

| 토큰 | 값 | 사용처 |
|------|------|--------|
| xs | 4px | 아이콘과 텍스트 사이 |
| sm | 6~8px | 태그 간격, 리스트 항목 내부 |
| md | 12~16px | 섹션 내부 패딩, 카드 패딩 |
| lg | 20~24px | 섹션 사이 간격 |
| xl | 28px | 좌우 페이지 패딩 |

### 페이지 구조

```
┌─────────────────────────┐
│← 28px →  콘텐츠  ← 28px→│  ← 좌우 패딩
│                         │
│ [섹션 라벨]      20px ↕ │  ← 섹션 간 간격
│ [콘텐츠]          8px ↕ │  ← 라벨과 콘텐츠
│                         │
│ [섹션 라벨]      20px ↕ │
│ [콘텐츠]               │
│                  70px ↕ │  ← 하단 탭 여백
└─────────────────────────┘
```

## 5. 컴포넌트 가이드

### 5-1. 체크 아이템 (Routine, Recommendation, Todo)

```
현재 문제: 체크 원 14px → 터치 영역 부족 (최소 44px 필요)

개선안:
┌─────────────────────────────────────┐
│ ○  아침 스트레칭 10분       3일째   │  ← 전체 행 높이 44px
│    ↑ 16px 원 + 14px 양쪽 패딩      │     터치 영역 = 전체 행
└─────────────────────────────────────┘

- 체크 원 시각 크기: 16px
- 행 전체가 터치 영역: min-height 44px
- 체크 상태: 빈 원(#60A5FA 테두리) → 채운 원(#60A5FA 배경 + 흰 체크마크)
- 완료 텍스트: #B3B3B3 + 취소선
- 연속 일수: 우측 정렬, 0.6rem, #60A5FA (3일+), #B3B3B3 ("잊지 않으셨죠?")
```

### 5-2. 버튼

```
Primary (저장, OK):
- 배경: #000000 (기본) / #60A5FA (저장 완료)
- 텍스트: #FFFFFF, 0.85rem, 600
- 높이: 44px
- 모서리: 10px
- 전체 폭

Secondary (추가, 기록):
- 배경: #60A5FA
- 텍스트: #FFFFFF, 0.7~0.75rem, 600
- 높이: 34px
- 모서리: 6px
- 내용 폭

Tertiary (취소, 변경):
- 배경: transparent
- 텍스트: #B3B3B3, 0.6rem
- 테두리: 없음
```

### 5-3. 태그/필

```
상태 태그:
- 패딩: 3px 8px
- 모서리: 12px
- 폰트: 0.62rem

건강 태그: color=#059669, bg=rgba(5,150,105,0.08)
감정 태그: color=#8B5CF6, bg=rgba(139,92,246,0.08)
날씨 태그: color=#808080, bg=#F2F2F2
미기록 태그: color=#B3B3B3, bg=#FAFAFA

감정 선택 버튼:
- 패딩: 5px 12px
- 모서리: 20px
- 폰트: 0.75rem
- 색: 각 감정 컬러
- 배경: 감정 컬러 12% opacity
- 테두리: 감정 컬러 40% opacity
```

### 5-4. 차트

```
바 차트:
- 달성: #60A5FA
- 미달성: #E6E6E6
- 바 간격: 1~3px
- 모서리: 2px (상단만)
- 마우스오버 하이라이트: #3B82F6

컬러 비율 바 (감정 Week):
- 높이: 12px
- 모서리: 6px
- 각 감정 색 비율대로

컬러 스트립 (감정 Month):
- 높이: 14px
- 모서리: 7px
- 일별 1칸, 간격 1px
- 미기록일: #F0F0F0

범례:
- 컬러 원: 8px
- 텍스트: 0.65~0.68rem, #333
- 간격: 8px
```

### 5-5. 카드

```
요약 카드 / 리포트:
- 배경: #FAFAFA
- 모서리: 8~10px
- 패딩: 12~16px
- 테두리: 없음
- 폰트: 0.78~0.82rem, #333, line-height 1.7

인사이트 액센트 라인:
- 왼쪽 2px solid #60A5FA
- 패딩-좌: 12~14px
```

## 6. 네비게이션

### 하단 탭 바

```
- 4탭: 홈 / 하루 / 기록 / 설정
- 높이: ~50px + safe-area
- 배경: #FFFFFF
- 상단 테두리: 1px solid #E6E6E6
- 활성 탭:
  - 이름: #000000, 0.82rem, 700
  - 역할: #60A5FA, 0.48rem, uppercase
  - 상단 인디케이터: 20px × 2px, #60A5FA
- 비활성 탭:
  - 이름: #B3B3B3
  - 역할: #B3B3B3
- 위치: fixed bottom, z-index 30
```

### 기록 서브 탭

```
- 3탭: Today / Week / Month
- 하단 테두리로 연결
- 활성 탭: #000000, 600, 하단 2px #60A5FA
- 비활성 탭: #B3B3B3, 400
- 대문자 (uppercase), letter-spacing 0.06em
```

| 컨디션 | 바 차트 | — | ✅ 30일 |
| Recommendation 달성률 | 바 차트 (opacity 비율) | 숫자 카드 | ✅ 30일 |
| 감정 분포 | 컬러 비율 바 | ✅ 비율 | — |
| 감정 흐름 | 컬러 스트립 | — | ✅ 30일 |
| 루틴 달성 | 프로그래스 바 | — | ✅ 항목별 |
| Todo | 숫자 카드 | ✅ 완료율 | — |

### 차트 공통 규칙

```
1. 범례는 차트 바로 아래에 (스크롤 필요 없이)
2. 마우스오버/터치 시 데이터 값 표시
3. 빈 데이터: #F0F0F0 (투명이 아닌 옅은 회색)
4. 블루 단일색 원칙 (감정만 예외)
5. 목표선이 있으면 점선으로 표시
6. 숫자 라벨: 차트 위에 직접 표시 (마우스오버 불필요하게)
```

## 8. 반응형 & 모바일

### 뷰포트

```
- width: device-width
- initial-scale: 1
- maximum-scale: 1 (iOS 확대 방지)
- user-scalable: no
```

### 터치 타겟

```
- 최소 터치 영역: 44×44px
- 체크 원: 시각 16px + padding으로 44px 확보
- 버튼: min-height 44px
- 입력 필드: min-height 44px
- 감정 태그 간격: 최소 8px
```

### iOS Safari 대응

```
- 모든 input/textarea: font-size 16px (확대 방지)
- position: fixed 사용 (sticky 대신)
- safe-area-inset-bottom 패딩
- Enter 키: 모바일=줄바꿈, 데스크탑=전송
```

## 10. 애니메이션

### 사용하는 애니메이션

```
- 저장 피드백: background 색상 전환 (0.3s)
- 체크 상태: 즉시 (애니메이션 없음)
- 탭 전환: 즉시 (SPA 라우팅)
- 날씨 그라디언트: transition-all 0.8s
```

### 원칙

```
- 장식적 애니메이션 없음
- 상태 전환만 (0.15~0.3s)
- reduced-motion 존중
```
