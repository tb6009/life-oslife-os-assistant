## 3. 하루 탭 (Assistant)

### 화면 구성

```
┌─────────────────────────────┐ ← 상단 고정 (fixed)
│ 하루                        │
│ 당신의 개인 비서             │
│ [수면5.7h,컨디션3/5] [기쁨] │ ← 상태 태그
├─────────────────────────────┤
│                             │
│ 하루: 안녕하세요! 오늘       │ ← 마크다운 렌더링 (**볼드**)
│       몸 상태는 어떠세요?    │
│                             │
│            오늘 좀 피곤해 :나│
│                             │
│ 하루: 피곤하시구나... 어젯밤 │ ← MI 공감 대화 스타일
│       잘 주무셨어요?         │
│                             │
│ 하루: 이런 방법이 있어요:    │
│   ☐ 수분 보충               │ ← 체크박스 (액션 감지 시)
│   ☐ 짧은 스트레칭            │
│   ☑ 호흡 연습               │
│   [Rec 추가] [Todo 추가]    │ ← 체크된 것만 저장
│                             │
├─────────────────────────────┤
│ [메시지 입력...]         🔵 │ ← 모바일: Enter=줄바꿈
└─────────────────────────────┘
```

### 하루 기능

| 기능 | 작동 방식 |
|------|-----------|
| 건강 기록 | "7시간 잤어" → 자동 DB 저장 |
| 감정 기록 | "막막해" → 자동 DB 저장 |
| 루틴 관리 | "명상 루틴 추가해줘" → routines 테이블 |
| API 확인 | "API 확인" → 연결 상태 표시 |
| 도움말 | "뭐 할 수 있어?" → 기능 안내 |
| Rec/Todo | 체크박스 → 선택 항목만 저장 |

### MI 공감 대화 원칙

```
❌ 바로 리스트 → ✅ 먼저 공감 대화
❌ "다음 포인트를 고려하세요" → ✅ "어떤 부분이 고민이세요?"
❌ 한번에 5개 나열 → ✅ "정리해드릴까요?" 후 동의 시 제공
```

## 6. 디자인 시스템

### 컬러

| 용도 | 색상 | 코드 |
|------|------|------|
| 강조/제목 | Black | #000000 |
| 본문 | Dark Gray | #333333 |
| 보조 | Gray | #808080 |
| 라벨 | Light Gray | #B3B3B3 |
| 구분선 | Border | #E6E6E6 |
| 배경 | White | #FFFFFF |
| 액센트 (시간 기반) | Blue | #60A5FA |
| 목표 달성 | Blue | #60A5FA |
| 목표 미달성 | Light Gray | #E6E6E6 |

### 타이포그래피

| 용도 | 폰트 | 크기 |
|------|------|------|
| 영문 제목 | Outfit 700 | 1.3~1.7rem |
| 한글 본문 | Noto Sans KR 400 | 0.82~0.84rem |
| 라벨 | Outfit 500 uppercase | 0.6rem |
| 날씨 온도 | Outfit 300 | 5.4rem |
| 입력 | system (16px) | iOS 확대 방지 |

### 인터랙션 원칙

- 체크: 원형 토글 (빈 원 → 블루 채움 + 체크마크)
- 저장: 버튼 클릭 → "저장 완료" (블루) 2초 표시
- 날짜: scroll-snap 피커, 가운데 날짜=검은 배경+흰 텍스트
- 차트: 마우스오버/터치 시 데이터 값 표시
- 모바일 Enter: 줄바꿈 (전송은 파란 버튼만)

## 7. 데이터 아키텍처

### Supabase 테이블 (12개)

```
health_logs        → 수면, 운동, 컨디션
journal_entries    → 감정, 메모, Daily Review 4질문, 감사
chat_messages      → 하루 대화 기록 (날짜별)
todos              → 할 일 (완료 시간 기록)
schedules          → 캘린더 일정
daily_insights     → 일일 인사이트
recommendation_logs → 추천 달성률
routines           → 루틴 항목 (추가/삭제)
routine_logs       → 루틴 일별 완료 기록
weekly_reviews     → 주간 회고
monthly_reviews    → 월간 회고
users              → 사용자 설정
```

### 데이터 흐름

```
사용자 → 하루 대화 → chat_messages + health_logs + journal_entries + routines
              ↓
         홈 탭 복귀 → Daily Insight (30분) + Recommendation (1시간) 갱신
              ↓
         기록 탭 → 날짜별 열람 + 주간/월간 리포트 자동 생성
              ↓
         회고 입력 → weekly_reviews / monthly_reviews 저장
```
