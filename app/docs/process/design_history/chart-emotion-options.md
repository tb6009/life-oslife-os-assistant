# 감정 시각화 — 컬러 차트 옵션 비교

> 2026-05-05 | Stage 7 UX Audit에서 도출된 감정 시각화 개선안

## 배경
- 현재: 감정을 태그로 나열 (`[기쁨] [평온] [피곤]`)
- 문제: 비율 파악 어려움, 시간 흐름 안 보임
- UX Audit 초기 제안: 도넛 차트
- 사용자 피드백: **"컬러 차트를 쓰면 어떨까"**

## 감정-컬러 매핑

| 감정 | 컬러 | 의미 |
|------|------|------|
| 기쁨 | #FBBF24 (골드) | 밝고 따뜻한 |
| 평온 | #60A5FA (블루) | 차분한 |
| 설렘 | #F472B6 (핑크) | 생기 있는 |

| 불안 | #A78BFA (바이올렛) | 불안정 |
| 짜증 | #FB923C (오렌지) | 뜨거운 |
| 슬픔 | #818CF8 (인디고) | 깊은 |

| 외로움 | #C4B5FD (라벤더) | 조용한 |

## Option A — 컬러 스트립 (일별 흐름)

```
EMOTION FLOW — 30 Days

■■■■□□■■□■■■■□□□■■■■□□■■■■□□□■
1   5    10   15   20   25   30

■ 기쁨  ■ 평온  ■ 피곤  □ 기록 없음
```

### 장점
- 30일간 감정 **흐름/패턴**이 한눈에 보임
- "이번 달 후반에 피곤이 많았구나" 직관적 파악
- 공간 효율적 (한 줄)

### 단점
- 색이 10종이면 구분 어려울 수 있음
- 색각 이상 사용자 대응 필요
- 범례 필수

### 접근성 대응
- 마우스오버/터치 시 "5/3: 기쁨" 텍스트 표시
- 범례에 텍스트 라벨 포함

## Option B — 컬러 그리드 (캘린더 형태)

```
EMOTION CALENDAR
일 월 화 수 목 금 토
         ■  ■  □  ■
■  □  ■  ■  □  ■  ■
■  ■  □  ■  ■  □  □
...
```

### 장점
- 히트맵 캘린더와 동일 형태 → 사용자 학습 불필요
- 요일별 패턴 파악 (월요일은 항상 피곤?)

### 단점
- 히트맵 캘린더(기록 유무)와 시각적으로 겹침 → 혼란
- 공간 많이 차지

---

## Option C — 컬러 비율 바 (비율 중심)

```
EMOTION DISTRIBUTION

████████████░░░░░░░░░░░░░
기쁨 40%  평온 30%  피곤 20%  기타 10%
```

### 장점
- 가장 심플, 한 줄
- 비율 즉시 파악
- 도넛 차트보다 공간 효율적

### 단점
- 시간 흐름 정보 없음
- 소수 감정은 너무 작아서 안 보임
