## 2. 상세 문제점

### 2-1. 접근성 (CRITICAL — 즉시 수정 필요)

| 문제 | 현재 | 기준 | 영향 |
|------|------|------|------|
| **aria-label 없음** | 0개 | 모든 인터랙티브 요소에 필요 | 스크린리더 사용자 완전 차단 |
| **폼 label 없음** | placeholder만 사용 | `<label for>`필요 | 접근성 위반 |
| **색만으로 정보 전달** | 블루=달성, 그레이=미달성 | 아이콘/텍스트 보조 필요 | 색각 이상 사용자 구분 불가 |
| **#b3b3b3 대비** | 77곳에서 사용 | 4.5:1 미달 (실제 2.6:1) | 읽기 어려움 |

### 2-2. 터치/인터랙션 (HIGH)

| 문제 | 현재 | 기준 | 위치 |
|------|------|------|------|
| **체크 원 크기** | 14×14px | 최소 44×44px | Routine, Recommendation, Todo |
| **컨디션 버튼** | 30×30px | 최소 44×44px | 기록 Today |
| **감정 태그 간격** | 4px | 최소 8px | 기록 Today |
| **터치 피드백 없음** | 클릭 시 시각 변화 없음 | 150ms 이내 피드백 | 모든 버튼 |

### 2-3. 차트/데이터 (개선 필요)

| 문제 | 현재 | 개선안 |
|------|------|--------|
| **바 차트만 사용** | 수면/컨디션/달성률 모두 바 차트 | 유형별 차트 분리 (아래 제안 참고) |
| **범례 없음** | 블루=7h+ 규칙 설명 없음 | 차트 하단 범례 |
| **숫자 라벨 없음** | 마우스오버 시만 표시 | 주요 값 직접 라벨링 |
| **빈 데이터 처리** | 바 높이 0% (보이지 않음) | "데이터 없음" 표시 |
| **Week vs Month 차트 동일** | 같은 형태 반복 | Week=간단 카드, Month=트렌드 라인 |
| **루틴 달성률** | 프로그래스 바만 | 와플 차트 또는 게이지 추가 |
| **감정 분포** | 태그 나열 | 도넛/레이더 차트로 비율 시각화 |

## 3. 차트/데이터 시각화 개선안

### 3-1. Week 탭 — 카드 기반 KPI + 미니 차트

**현재**: 달성률 숫자 + 바 차트 + 태그 나열

**개선안**:

```
┌─────────┬─────────┐
│  72%    │  6.4h   │
│  Rec    │  수면   │
│  ██████░│  ██████░│  ← 미니 프로그래스 링
├─────────┼─────────┤
│  3/4    │  3.6/5  │
│  루틴   │  컨디션  │
│  ███░░░░│  ████░░░│
└─────────┴─────────┘

SLEEP (라인 차트 — 트렌드 강조)
 8h ─────────────────── 목표선
    ╱╲    ╱╲
   ╱  ╲  ╱  ╲╱
 4h ───────────────────
   일 월 화 수 목 금 토

EMOTION (도넛 차트)
   기쁨 40% ██
   평온 30% █
   피곤 20% █
   감사 10% ░
```

**핵심 변경**:
- 바 차트 → **라인 차트** (수면 트렌드 한눈에)
- 목표선(7시간) 표시 → 달성/미달성 즉시 파악
- 감정 태그 → **도넛 차트** (비율 시각화)
- 4개 KPI → **프로그래스 링** (공간 효율적)

### 3-2. Month 탭 — 히트맵 + 트렌드 라인 + 와플

**현재**: 히트맵 + 바 차트 × 3 + 프로그래스 바

**개선안**:

```
히트맵 캘린더 (유지 — 잘 되어 있음)

SLEEP TREND (라인 차트 — 30일 트렌드)
 8h ─ ─ ─ ─ ─ ─ ─ ─ ─ 목표
     ╲╱╲  ╱╲╱╲╱╲  ╱╲
        ╲╱      ╲╱
 4h ─────────────────────
   1    5    10   15   20   25   30

CONDITION (라인 — 수면과 겹쳐서 상관관계)
 수면 ── 컨디션 - - -
    ╱╲    ╱╲         ← 수면 높은 날 = 컨디션 높은 날?
   ╱  ╲  ╱  ╲

ROUTINE (와플 차트 — 30일 중 몇일)
스트레칭  ■■■■■■□□□□ 20/30 (67%)
물 8잔   ■■□□□□□□□□ 15/30 (50%)
감사일기  ■■■■■■■■□□ 25/30 (83%)  ← 색 채움=완료
30분운동  ■■■□□□□□□□ 10/30 (33%)

EMOTION (레이더 차트 — 5각형)
        기쁨
       ╱    ╲
     평온 ── 감사
       ╲    ╱
        피곤
```

**핵심 변경**:
- 바 차트 → **라인 차트** (30일 트렌드 파악)
- 수면+컨디션 **겹침 비교** (상관관계 발견)
- 목표선 표시 (수면 7시간)
- 루틴 프로그래스 바 → **와플 차트** (30일 중 며칠 직관적)
- 감정 태그 → **레이더 차트** (감정 균형 시각화)

### 3-3. 홈 — Recommendation 시각화

**현재**: 체크 리스트만

**개선안**:
```
RECOMMENDATION              ████░ 3/5 (60%)
                            ← 미니 프로그래스 바 추가
수면이 부족해요...

☑ 수분 보충
☐ 스트레칭
☑ 호흡 연습
```

상단에 미니 프로그래스 바로 달성률을 시각적으로 표시.

## 5. 차트 라이브러리 추천

현재 순수 div/CSS로 차트를 만들고 있습니다. 개선안을 구현하려면:

| 옵션 | 라이브러리 | 장점 | 단점 |
|------|-----------|------|------|
| **A (추천)** | 순수 SVG | 번들 크기 0, 완전 제어 | 복잡한 차트 어려움 |
| **B** | Recharts | React 네이티브, 선언적 | 번들 +50KB |
| **C** | Chart.js | 가볍고 다양 | React 래퍼 필요 |

**추천: A (순수 SVG)** — 라인 차트, 도넛 차트, 와플 차트 모두 SVG로 충분히 구현 가능. 외부 의존성 없음.

## 6. 디자인 시스템 추천 비교

| 항목 | 현재 Life OS | UI Pro Max 추천 |
|------|-------------|-----------------|
| 스타일 | 미니멀 텍스트 중심 | Biomimetic / Organic (웰니스에 적합) |
| 컬러 | #60A5FA 단일 | #0EA5E9(Primary) + #059669(Accent) 추가 고려 |
| 폰트 | Outfit + Noto Sans KR | Lora + Raleway 제안 (더 웰니스 느낌) |
| 차트 | div/CSS 바 | SVG 라인 + 도넛 + 와플 |

**의견**: 현재 Outfit + Noto Sans KR + 블루 단일 컬러는 **프로덕티비티 툴** 느낌이 강합니다. 이대로도 좋지만, 만약 **웰니스/라이프 관리** 느낌을 더 강조하고 싶다면 따뜻한 악센트(#059669 그린)를 건강 관련 요소에 추가하는 것을 고려해볼 수 있습니다.
