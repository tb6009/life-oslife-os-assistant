💡 추천: 방식 4 (⋯ 메뉴 통합)

평소 화면은 항상 깔끔하고 (⋯ 점 3개만), 필요할 때 펼치면 "잠깐 쉬기 / 종료일 / 삭제" 모두 한 곳에서 처리됩니다. UI 복잡도 우려는 해결되면서, 상황별 유연성도 확보.

구현도 단계적 가능:

  • 1차: ⋯ 메뉴에 "삭제"만 (현재 ✕ 버튼 대체)
  • 2차: "잠깐 쉬기" 추가
  • 3차: "종료일 설정" 추가 (실제 필요 느낄 때)

즉 1차만으로도 UI는 깔끔해지고, 나중에 옵션만 늘리면 됨.
