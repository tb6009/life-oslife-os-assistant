A안 — 진행 로그 + 마무리
투두에 "오늘 했다" 추가
  • ▶ 버튼 = 오늘 진행 로그 (pending 유지)
  • ✓ 버튼 = 마무리 (Done으로 이동)
  • 점 표시로 "N일째 진행" 시각화
  • Done에 "6일 작업" 메타 자연 연결
  • 의미가 가장 정확. 며칠짜리 작업과 일회성을 한 리스트에서 다 처리.
  • 새 테이블(todo_progress_logs) 1개 필요.

B안 — 루틴 승격
"며칠" 토글 → 루틴화
  • 다일 작업은 Routine 영역으로 이동
  • 기존 RoutineList 그대로 재사용
  • "다일 작업" 배지로 진짜 루틴과 구분
  • DB 변경 없음. 기존 streak 로직 그대로.
  • 의미 혼선: 루틴(매일 반복)과 다일 작업(끝 있음)이 한 칸에 섞임.
  • "끝"을 어떻게 표현할지 별도 설계 필요 (루틴은 원래 끝이 없음).

A안 — 진행 로그 + 마무리
세 안 중 사용자 피드백의 의도("끝낸 것과 오늘 했다는 진행")를 가장 정확히 반영함. 며칠 걸리는 일회성 작업(논문·기획)과 매일 반복하는 루틴(스트레칭)은 본질이 다르므로 한 영역에 섞는 B안은 장기적으로 의미 혼선. C안은 같은 UI를 보여주지만 데이터가 안 남아 v0.9.7의 "소요일 메타"·"회고 picking" 가치와 연결되지 않음.

A안은 새 테이블 1개라는 비용이 있지만, 이미 운영 중인 ActivityTracker / Done 소요일 메타와 자연스럽게 통합되어 Life OS 전체의 "활동 누적 → 회고" 흐름을 강화함.
