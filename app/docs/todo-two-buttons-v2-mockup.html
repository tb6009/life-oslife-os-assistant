v2 — C안 기본 + B안 진행일수 머지
한 줄에 진행 상태가 다 보이는 minimal 디자인
  • 행 구조: [제목 + 메타] [진행일수 배지] [오늘] [완료] — 우측에 액션·상태 묶음
  • 오늘 버튼: 누르면 파란색 활성 상태(.today)로 바뀌고 메타에 "마지막 진행 오늘" 갱신
  • 완료 버튼: 누르면 Done 섹션으로 이동 (기존 동작 그대로)
  • 진행일수 배지 색상 규칙 (Done의 소요일 색상 규칙과 통일):
    • · — : 진행 없음 (회색·옅음)
    • · 1~2일째 : 회색 (조용)
    • · 3~6일째 : amber (지속)
    • · 7일+ 째 : red (오래 묵힘, 회고 신호)
  • "N일째" 의미: 시작일부터 오늘까지 경과일 (연속 진행이 아닌 묵힌 정도) — 5/23 시작이면 5/30 = 8일째
  • "N일 진행" (Case 5): 실제 "오늘" 누른 횟수 누적. 끊긴 적 있으면 별도 표시
데이터 · 구현 비용
todos 테이블에 2개 컬럼만 추가 — 새 테이블 없음.
· last_progressed_at TIMESTAMPTZ — 마지막 "오늘" 누른 시각
· progress_count INT DEFAULT 0 — "오늘" 누른 총 횟수 (Case 5의 "2일 진행")

"N일째"는 today - created_at 계산식으로 클라이언트에서 산출 → 별도 저장 X.
ActivityTracker에는 last_progressed_at 변경일을 1포인트로 카운트.

예상 작업량: 마이그레이션 1개 + TodoList 컴포넌트 + API 2개(progress/undo) ≈ 2~3시간.
