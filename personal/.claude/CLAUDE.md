- ✅ 본 폴더에서 작업 중일 때 Gmail/Calendar MCP 호출 가능
- ❌ 다른 프로젝트(05_DSAPG, 21_연구논문02 등) 컨텍스트에서 Gmail/Calendar MCP 호출 금지

- 메일에서 추출한 정보는 본 폴더 `data/schedule/` 등에만 저장
- 캘린더 변경(생성·수정·삭제) 전 반드시 주인님께 표로 확인받은 후 실행

## 작업 규칙

1. 일일 브리핑 생성 시 `playbooks/morning_briefing.md` 절차 준수
2. 새 파일 명명: `YYYY-MM-DD.md` (일일), `YYYY-WNN.md` (주간), `YYYY-MM.md` (월간)
3. 데이터 파일은 마크다운 우선. 표로 정리 가능하면 표 사용
4. 파일 삭제·덮어쓰기 전 사용자 확인 필수
5. 참조 무결성: 외부 페르소나 원본은 절대 수정·이동 금지

## 출력 규약

- 진의 보고는 **3블록 이내**로 짧게: ① 어제 ② 오늘 ③ 한 가지 권고
- 이모지·과도한 마크다운 강조 자제 (정중함 유지)
- 모미·마음이 발화할 때만 그들의 톤 허용
