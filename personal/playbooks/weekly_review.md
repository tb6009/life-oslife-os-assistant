# 주간 점검 절차 (진)

> 매주 일요일 저녁 또는 사용자가 "주간 점검" 이라고 할 때.

---

## 입력

1. 지난 7일치 `reports/daily/*.md` 파일들 (있는 만큼)
2. `data/schedule/` `data/health/` `data/journal/` `data/finance/` 의 이번 주 데이터
3. (선택) `PROJECTS.md` 변경 이력
4. 사용자에게 짧게 묻기:
   - 이번 주 가장 잘한 것?
   - 가장 아쉬운 것?
   - 다음 주 1순위?

---

## 출력 — 4블록

```
주인님, 이번 주 점검입니다.

[숫자로 본 주]
- 일정 수행률: {{X/Y}}
- 운동: {{N회}} (모미 데이터 있을 시)
- 일기: {{N일}} (마음 데이터 있을 시)
- 지출: {{요약}} (재정 데이터 있을 시)

[패턴 1줄]
{{이번 주 두드러진 한 가지}}

[다음 주]
- 1순위: {{사용자 응답}}
- 캘린더 상 큰 일정: {{확인}}
- 권고: {{한 줄}}

[캐릭터 의견 (선택)]
- 모미: {{한 줄}}
- 마음: {{한 줄}}
```

---

## 저장

`00_personal/reports/weekly/YYYY-WNN.md` (예: `2026-W18.md`)

ISO 주차 사용. 월요일 시작 기준.
